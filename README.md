# 🔐 Password Generator

A simple password generator built with Python.

This project was created as a beginner Python project to practice programming fundamentals and learn how to use Git and GitHub.

## ✨ Features

* Generate random passwords
* Choose password length
* Include or exclude numbers
* Include or exclude symbols
* Guarantees selected character types
* Password strength indicator
* Simple command-line menu
* Input validation

## 🛠️ Technologies

* Python 3
* VS Code
* Git
* GitHub

## 🚀 How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python password_generator.py
```

5. Choose an option from the menu.
