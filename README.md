# ⚡ Quantum Secure Password Generator

A sleek, cyberpunk-themed desktop password generator built using **Python** and **CustomTkinter**.

---

## ✨ Features
- **Modes:** Standard Passwords, Memorable Passphrases, and Numeric PINs
- **Security Telemetry:** Real-time Shannon entropy calculation and estimated time-to-crack
- **Customizable Pool:** Toggle Uppercase, Numbers, Symbols, and exclude ambiguous characters (`0, O, l, 1, I`)
- **Auto-Clearing Clipboard:** Clears copied passwords after 30 seconds for security
- **Session History:** Keeps a live feed of your last 4 generated keys
